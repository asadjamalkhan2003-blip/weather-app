# weather-app
A responsive Weather App built using HTML, CSS, and JavaScript. It fetches real-time weather information using a Weather API.

## ✨ Features

- Search weather by city name
- Displays temperature
- Shows humidity
- Shows wind speed
- Responsive design
- Clean and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API
